# Changelog

## 6.0.0 - 2026-07-15

### Added
- Complete native uGUI Creative Editor replacing the legacy workflow.
- Player pronoun, appearance, Genodriver, equipment and lifecycle tools.
- Monster genealogy, batch operations, jobs, species normalization and trait catalog cards.
- Universal inventory containers, category/search filters and item metadata.
- Egg, farm, quest, world, dungeon, combat, gallery and relationship editors.
- Transaction/Undo history, automatic rotating save backups and restore tools.
- Compatibility report, runtime diagnostics and error center.

### Quest reliability
- Canonical quest discovery with ID deduplication and deterministic status sorting.
- Search across quest/step names and IDs.
- Safe dependency planning, step inspector, log audit/repair and runtime resynchronization.
- Protection from duplicate quest rewards.

### Fixed
- Adaptive overlay layout, hit testing, cursor visibility and smooth persistent scrolling.
- Invalid protagonist ability states causing `GetAbilityWithIndex` crashes.
- Gender-swap appearance refresh.
- Trait descriptions and quality colors.
- NoClip and movement speed placement under Cheats.
