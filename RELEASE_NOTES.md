# Cloud Meadow Creative Mode v6.0.0

Совместимость: **Cloud Meadow Beta v0.2.6.1** — актуальная версия игры на момент релиза.

## Кратко

- Полностью новый адаптивный uGUI-интерфейс Creative Editor.
- Перенесены редакторы героя, монстров, traits, инвентаря, фермы, яиц, квестов, мира, подземелий, боя и галереи.
- Новый Quest Inspector: корректный список без дублей, статусы, поиск, зависимости, Safe Jump, Repair и Undo.
- Добавлены Transaction/Undo, автоматические резервные копии, Compatibility Diagnostics и Error Center.
- Инвентарь получил контейнеры, поиск, категории, массовое выделение и расширенные данные предметов/яиц.
- Traits отображаются сеткой с игровыми описаниями и цветами качества.
- NoClip и скорость перенесены в Cheats; добавлены готовые пресеты.

## Важные исправления

- Исправлены gender swap и обновление внешности героя.
- Исправлены курсор, hitboxes, адаптивность и плавная прокрутка меню.
- Исправлена повторная выдача наград квестов и синхронизация Quest UI после Repair/Undo.
- Добавлена автоматическая починка некорректных Ability State героя, вызывавших `GetAbilityWithIndex` crash.

## Установка

Распаковать архив в корень игры. Итоговый путь DLL:

`BepInEx/plugins/CloudMeadowCreativeMode/CloudMeadow.CreativeMode.dll`

Открытие редактора: **F6**.
